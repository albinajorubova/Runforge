# Runforge

Dashboard for browsing and inspecting AI agent runs.

## Stack

- React
- TypeScript
- Vite
- SCSS Modules
- Biome
- pnpm

## Development

```bash
pnpm install
pnpm dev
```

## Checks и test

```bash
pnpm test
pnpm check
pnpm build
```

## Структура

- `src/App/` — главный экран и тесты.
- `src/components/` — компоненты интерфейса.
- `src/hooks/`, `src/services/`, `src/data/` — логика и данные запусков.
- `src/model/` — типы данных.
- `src/styles/` — общие стили.
