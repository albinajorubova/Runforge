# Runforge

Dashboard for browsing and inspecting AI agent runs.

## Stack

- React
- TypeScript
- Vite
- SCSS Modules
- Biome
- pnpm

## Development

```bash
pnpm install
pnpm dev
```

## Checks

```bash
pnpm check
pnpm build
```

Biome is intentionally configured with a minimal baseline in `biome.json` so it can be adjusted for the project conventions.
